# Agricultural Data Analysis Using Data Analytics

## Project Overview

This project focuses on analyzing agricultural data from selected districts of Maharashtra using crop insurance claims, rainfall records, and crop yield statistics.

## Objectives

* Organize agricultural datasets for analysis.
* Explore crop insurance claims across districts and years.
* Analyze rainfall patterns and crop yield trends.
* Use SQL queries to investigate patterns across the datasets.
* Develop visualizations to communicate meaningful insights.

## Dataset

The project uses three categories of agricultural data:

* PMFBY crop insurance claims
* Rainfall records
* Crop yield statistics

The analysis focuses on selected districts of Maharashtra over multiple years.

## Tools and Technologies

* Microsoft Excel
* MySQL Workbench
* Python
* Power BI

## Project Workflow

1. Data collection and validation
2. Data cleaning and preparation
3. Database table creation using MySQL
4. SQL querying and exploratory analysis
5. Data visualization and interpretation
